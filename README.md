# Image Vasto Lorde
When enabled, will display a custom image on the client.

Place a PNG or GIF named profile in %userprofile%\\.runelite\ on Windows or ~/.runelite/ on Linux/OSX.

## Update image
Once the plugin finds an image, it saves it in memory. Simply changing profile.png will update what you see.

## Nameplate
To create a full nameplate, combine with a plugin like RHUD that displays your name, health, and prayer: https://runelite.net/plugin-hub/show/rasta-hud
