# Image Vasto Lorde

ImageVastoLorde is a fork and substantial enhancement of the original Image Bankai plugin by DeadRobotDev. The project retains the original BSD-2-Clause license and attribution.

When enabled, will display a custom image on the client.

The plugin automatically creates the ImageVastoLorde folder.

Place a PNG or GIF named profile in %userprofile%\\.runelite\ImageVastoLorde on Windows or ~/.runelite/ImageVastoLorde on Linux/OSX.

## Update image
Once the plugin finds an image, it saves it in memory. Simply changing profile.png will update what you see.

## Nameplate
To create a full nameplate, combine with a plugin like RHUD that displays your name, health, and prayer: https://runelite.net/plugin-hub/show/rasta-hud
